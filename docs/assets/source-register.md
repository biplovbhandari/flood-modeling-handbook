# Visual Source Register

All nine figures are original handbook assets created as code-native SVGs.
Except where otherwise noted, they are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), which requires attribution and an indication of changes.
The figures are schematic teaching material rather than measured geometry, model output, or reproduced textbook artwork.

| ID | Visual | Teaching purpose | Source and reuse |
| --- | --- | --- | --- |
| VIS-001 | [Stage, depth, and datum](stage-depth-datum.svg) | Distinguishes terrain elevation, WSE, depth, stage reference, discharge, velocity, and vertical datum. | Original handbook asset; CC BY 4.0. |
| VIS-002 | [Hydrology to hydraulics](hydrology-to-hydraulics.svg) | Traces precipitation, runoff, routing, discharge selection, and hydraulic inflow while preserving the hydrology-hydraulics boundary. | Original handbook asset; CC BY 4.0. |
| VIS-003 | [Open-channel downstream controls](open-channel-controls.svg) | Compares a slope-based normal-depth condition with a raised specified downstream WSE and its possible upstream influence. | Original handbook asset; CC BY 4.0. |
| VIS-004 | [Grid flux and wetting](grid-flux-wetting.svg) | Shows face-flux accounting, active and inactive cells, and a dry-to-wet transition on a structured grid. | Original handbook asset; CC BY 4.0. |
| VIS-005 | [Convergence evidence lanes](convergence-evidence.svg) | Separates numerical stability, process status, storage convergence, mass balance, hydraulic adequacy, and acceptance. | Original handbook asset; CC BY 4.0. |
| VIS-006 | [Model-development chain](model-development-chain.svg) | Connects prepared network, terrain, and land cover to realized artifacts, model identity, publication, and a separate evidence gate. | Original handbook asset; CC BY 4.0. |
| VIS-007 | [Adaptive discharge proposal and measured verdict](nd-adaptive-selection.svg) | Demonstrates that a predicted proposal window and a later measured response answer different questions. | Original handbook asset; CC BY 4.0. |
| VIS-008 | [Downstream-to-upstream stage transfer](kwse-stage-transfer.svg) | Separates physical flow, upstream information dependency, grid mapping, stage calculation, execution, and observation. | Original handbook asset; CC BY 4.0. |
| VIS-009 | [Validation evidence chain](validation-evidence-chain.svg) | Shows how input verification, numerical evidence, validation, uncertainty, acceptance, monitoring, and diagnosis remain distinct. | Original handbook asset; CC BY 4.0. |
